# 小暖｜产品与 AI 工作流存档

最后更新：2026-07-29

本文件是项目长期事实来源。后续改动应先阅读本文件，并同步更新对应代码；不得仅依赖聊天记录。

## 产品形态

- 产品名：小暖。
- 长者端：全屏数字人陪聊。长者只需语音输入；不展示聊天记录或键盘。
- 家属端：主页、日报、设置。家人资料、长者画像、日程、音色授权都在设置中维护。
- 数字人：小快的视频素材。默认显示静态首帧；只有系统正在输出语音时播放，语音结束立刻暂停。
- 其他家庭成员没有对应视频时使用静态头像，不能播放小快视频冒充他人。

## 实时语音陪聊

路径：`app/templates/elder.html` → `POST /api/chat` → `app/api/chat.py`。

1. 长者说话，浏览器 SpeechRecognition 转写。
2. 后端读取该成员、长者画像与已建档的真实家庭资料。
3. 若命中跌倒、胸痛、呼吸困难、走失、误服药、自伤、受威胁、疑似侵害或财务控制等风险词，跳过模型闲聊，输出简短安全升级建议。
4. 非风险内容调用 DeepSeek；实时陪聊 system prompt 位于 `app/api/chat.py`。
5. 后端拦截虚构现实行动和承诺（例如“我明天一定来看您”）。
6. 使用该成员已授权的 MiniMax 克隆音色合成语音。合成失败时，前端可用系统语音兜底。
7. 前端播放音频时启动数字人视频；音频结束或失败即暂停视频。

## 实时陪聊不可违反的原则

- 先回应情绪，后回应事实；短句、一次一个主题、至多一个低负担问题。
- 不考记忆：不说“你还记得吗”“你怎么又忘了”“考考您”。
- 不 infantilize（哄小孩、训诫、居高临下），不强迫回答或纠正叙述。
- 只使用建档事实；不编造家人的位置、行为、探望、日程、天气、饮食、回忆或病情。
- 不替现实家人承诺来访、电话、接送、就医、服药、转账或其他行动。
- 不索取密码、银行卡、验证码、地址、财产等敏感信息；不挑拨家属关系或制造依赖。
- 不提供诊断、改药建议或治疗承诺。风险出现时优先确保当下安全并联系身边可信照护者／紧急服务。

## 自动播报

路径：`app/services/pipeline.py`。

- `SYSTEM_PERSONA`：自动播报总人格。它是经家属授权的陪伴播报系统，不是假装现实家人。
- `MORNING_PROMPT`：只使用实时天气、真实日程和建档资料。
- `NOON_PROMPT`：熟悉感陪伴；不测试记忆。中重度一次一位家人，轻度最多两位。
- `EVENING_PROMPT`：只回顾真实发生事项及真实明日安排。
- `MEMBER_GREETING_PROMPT` 与 `MEMBER_INTRO_PROMPT`：按家人生成播报／介绍，只用真实档案，不要求老人认出或点击头像。
- `TIMESTAMPS_PROMPT`：将已生成播报稿中的家人片段转成 JSON 时间轴，仅用于界面联动。

所有播报均禁止：虚构行动、虚构探望、虚构回忆、替家属承诺、要求老人点击屏幕、要求老人证明记忆。
